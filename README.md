# E-Commerce Sales & Customer Intelligence
E-commerce sales and customer analysis using Python, SQL and Power BI.
## Tools & Technologies
-Python
-SQL
-Power BI
-Pandas
-NumPy
-Matplotlib
-Seaborn
## Project Overview
This project analyzes e-commerce sales data to identify sales trends, customer insights, product performance, and business KPIs.

The project includes in interactive Power BI dashboard for sales and customer analysis.
